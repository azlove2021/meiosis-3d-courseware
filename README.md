# S-01 减数分裂全流程时间轴

高中生物必修2《遗传与进化》2.1 减数分裂的交互式 3D 课件（three.js，离线单页）。

- 🌐 在线预览（GitHub Pages）：<https://azlove2021.github.io/meiosis-3d-courseware/>
- 📦 仓库地址：<https://github.com/azlove2021/meiosis-3d-courseware>

## 打开方式

双击 `S-01_减数分裂.html` 即可，无需服务器、无需构建。

- 依赖：`libs/three.min.js`（three.js r128，已随包提供）
- 若 `libs/` 缺失，会自动回退到 CDN 加载

## 模型与统计口径

- 模型起点：**初级精母细胞**（不是精原细胞），2n = 4，两对同源染色体
- 终点：**4 个精细胞**，每个 n = 2；精细胞还需变形才能成为成熟精子
- 颜色（红/蓝）仅用于区分父源/母源，**不是真实染色体颜色**
- 非真实显微比例，仅作示意
- **教材依据**：人教版 2019 必修2《遗传与进化》第2章第1节 减数分裂（每个阶段在右侧面板标注对应小节）

## 界面与操作

| 区域 | 内容 |
|---|---|
| 顶部 | 标题、语音开关、简洁模式、全屏、复位视角、重置课件 |
| 舞台顶部 | 10 个状态导航，按「间期 / 减数第一次分裂 / 减数第二次分裂」分组 |
| 舞台中央 | 三维细胞、染色体、着丝粒、纺锤丝、赤道板、四分体与交叉点标注 |
| 右侧面板 | 当前阶段讲解（可朗读）、实时读数、数量曲线、要点、易错点、观察任务 |
| 底部 | 播放/暂停、上一/下一阶段、时间轴、交叉互换、排列 A/B、速度 |

| 操作 | 方式 |
|---|---|
| 旋转 / 缩放 | 左键拖拽 / 滚轮 |
| 播放 / 暂停 | 空格，或点「播放」 |
| 单步切换 | ← →，或「上一阶段 / 下一阶段」 |
| 任意定位 | 拖动底部时间轴，或点顶部阶段按钮 |
| 交叉互换 | 勾选「交叉互换」，在前期Ⅰ看到片段交换与重组结果 |
| 自由组合 | 点「排列 A / B」，切换中期Ⅰ的排列方式，观察不同配子组合 |
| 高亮同源染色体 | 点击任意一条染色体 |
| 简洁模式 | 隐藏背景光斑、细胞质颗粒与发光，适合投影 |
| 复位视角 | 只复位镜头与高亮，不改变阶段 |
| 重置课件 | 时间、交叉互换、排列方式、选择、语音、镜头全部回到初始 |
| 全屏 | `F` 键或「全屏」 |

## 语音讲解

使用浏览器内置 `speechSynthesis`（中文），不依赖网络与外部音频。

- 默认开启自动朗读：手动切换阶段时朗读该段讲解
- 播放动画时不自动朗读，避免旁白与画面节奏互相打断
- 切换阶段会立即停止上一段朗读
- 首次进入需先点击页面任意位置，浏览器才允许发声
- 若系统没有中文语音，可到 Windows「设置 → 时间和语言 → 语音」安装中文语音包

```
S-01_减数分裂.html?t=9&arr=1           # 末期Ⅱ + 排列方式 B
S-01_减数分裂.html?t=6&voice=0         # 关闭语音
S-01_减数分裂.html?simple=1            # 简洁模式
```
